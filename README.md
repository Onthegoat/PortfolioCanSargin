## Projektbeschreibung

Das Portfolio dient als persönliche Website, um Projekte, Fähigkeiten und Informationen über mich zu präsentieren. Fokus auf modernes Design und Responsivität.

---

## Technologien

-   **HTML5**: Struktur der Website
-   **CSS3**: Styling und Layout (inkl. Media Queries für Responsivität)
-   **JavaScript**: Interaktive Features (z. B. Glider.js für Karusselle)
-   **Glider.js**: Für die Implementierung eines responsiven Karussells

---

## Installation

1. **Repository klonen**:
    ```bash
    git clone https://github.com/username/PortfolioCanSargin.git
    ```
2. **In das Projektverzeichnis wechseln**:
    ```bash
    cd PortfolioCanSargin
    ```
3. **Öffnen der `index.html` im Browser**:
    - Öffne die Datei `index.html` direkt in einem Browser, um die Website anzuzeigen.

---

## Verwendung

-   Navigiere durch die verschiedenen Abschnitte der Website:
    -   **Home**: Begrüßung und Einführung
    -   **Über mich**: Informationen über Can Sargin
    -   **Fähigkeiten**: Darstellung der technischen Fähigkeiten
    -   **Projekte**: Präsentation abgeschlossener Projekte
    -   **Kontakt**: Möglichkeit zur Kontaktaufnahme

## Projektstruktur

```
PortfolioCanSargin/
│
├── assets/               # Bilder und andere Medien
├── css/                  # CSS-Dateien
│   ├── _hero.css         # Styling für den Hero-Bereich
│   ├── _uebermich.css    # Styling für den "Über mich"-Bereich
│   ├── _faehigkeiten.css # Styling für den Fähigkeiten-Bereich
│   ├── _projekte.css     # Styling für den Projekte-Bereich
│   ├── _kontakt-footer.css # Styling für den Footer
│   └── main.css          # Haupt-CSS-Datei
│
├── javascript/           # JavaScript-Dateien
│   └── script.js         # Haupt-JavaScript-Datei
│
├── [`index.html`](index.html )            # Haupt-HTML-Datei
├── [`README.md`](README.md )             # Dokumentation
└── package.json          # (Optional, falls npm verwendet wird)
```

## Features

-   **Responsives Design**: Optimiert für Desktop, Tablet und Mobilgeräte.
